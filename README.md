# Eqraa - Book Store App

Eqraa is a modern Flutter bookstore application that provides a smooth and user-friendly experience for discovering, browsing, and purchasing books.  
The app features a clean UI, responsive design, and organized architecture to deliver an efficient mobile reading marketplace experience.

Built with Flutter and Firebase technologies to support scalability, performance, and cross-platform compatibility.
